# ENCReload documentation

**ENCReload** is a comprehensive gameplay overhaul for **Humankind** — hundreds of historical technologies, units,
districts and mechanics, extending every era from the Ancient World to the near future while keeping the feel of the
original game. The [project overview and feature list](https://github.com/sswelm/ENCReload#readme) lives on the repo
home; this page is the map of the docs themselves.
